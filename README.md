# divideandconquer.is-a.dev

Personal GitHub Pages website for `Heartspell`.

## Publish

1. Create a GitHub repository named `Heartspell.github.io`.
2. Upload these files to its `main` branch.
3. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Wait for GitHub Pages to publish the site.
